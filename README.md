# Vowbound

Unreal Engine 5.8 기반으로 개발 중인 개인 프로젝트입니다.

## 이 저장소에 관하여

비공개 개발 저장소의 현재 소스를 정리한 **코드 열람용 스냅샷**입니다. 원본의 커밋 기록은 포함하지 않습니다.

- `Source/`: 게임 및 테스트 모듈의 C++ 소스와 빌드 규칙
- `Config/`: 프로젝트 설정. 개발용 Android File Server 설정 제외
- `Vowbound.uproject`: 프로젝트 모듈과 엔진 플러그인 설정

게임 에셋, Blueprint, 맵, 실행 파일은 포함하지 않습니다. 따라서 이 저장소만으로 완전한 게임 실행이나 에디터 재생은 할 수 없습니다.

## 공개용 정리 범위

개인 AI 도구 설정, 내부 개발 문서, IDE 생성 파일, 개발 도구용 플러그인은 제외했습니다. 제외한 플러그인의 프로젝트 참조도 정리했습니다. 게임 소스 자체는 변경하지 않았습니다.

## 검증 범위

공개용 정리 이후 비밀값 자동 검사와 원본 대비 게임 소스 동일성 검사를 수행합니다. 이 사본의 Unreal 빌드, PIE, 패키징은 검증하지 않았습니다.

## 권리 범위

이 저장소를 공개하는 것과 별도의 오픈소스 라이선스를 부여하는 것은 다릅니다. 별도 라이선스를 지정하지 않았으며, 기존 소스의 저작권 표기는 유지합니다.
